# محطة التعرف على الوجه الذكية والحضور البيومتري للكمبيوتر
### 🚀 AI FaceID Desktop Workstation Pro (Biometrics & Attendance)

نظام أمني متكامل واحترافي للتعرف على الوجوه بالذكاء الاصطناعي مخصص لأجهزة الكمبيوتر والمحطات المكتبية (**Desktop PC / Workstation**)، مزود بواجهة بيومترية مستقبلية (**Cyberpunk HUD**)، تتبع المعالم الوجهية، كشف التزييف، معالج تسجيل الوجوه متعدد الزوايا (3D)، سجل حضور وانصراف وساعات عمل متقدم مع التصدير إلى Excel/CSV، وبوابة عمل سحابية محلية محمية.

---

## 🌟 أبرز مميزات النظام المطور للكمبيوتر

1. **واجهة بيومترية سايبربانك (Cyberpunk Biometric HUD):**
   - شبكة تتبع المعالم الوجهية الخمسة (**5 Facial Landmarks**): العينين، الأنف، وزوايا الفم عبر شبكة **YuNet ONNX**.
   - خطوط اتصال هندسية ذكية (**Biometric Connection Mesh**) وأقواس زوايا مضيئة على الوجه.
   - كشف الحيوية وجودة الملمس (**Liveness & Anti-spoofing Heuristic**) عبر تباين ملمس لابلاسيان لمنع استخدام الصور والشاشات الباهتة.
   - تحذير فوري عند رصد أكثر من شخص أمام الكاميرا (**⚠️ Multi-Face Alert**).

2. **قائمة اختيار كاميرات الـ USB المتصلة (Webcam Device Selector):**
   - فحص وتحديد تلقائي لجميع كاميرات الـ USB أو كاميرات اللابتوب المتصلة والتبديل بينها مباشرة من واجهة النظام.

3. **المساعد الصوتي باللغة العربية ومؤثرات الصوت (Arabic Voice Assistant):**
   - نطق صوتي ترحيبي وتوجيهي باللغة العربية عند القبول، الرفض، وخطوات تسجيل الزوايا.
   - نغمات ومؤثرات إلكترونية بيومترية مع زر كتم/تشغيل الصوت بنقرة واحدة.

4. **نظام الحضور والانصراف وساعات العمل اليومية (Attendance & Hours):**
   - تبويب مستقل يعرض حضور الموظفين لليوم أو لأي تاريخ محدد.
   - حساب توقيت أول تسجيل دخول (**First In**)، وآخر تواجد (**Last Seen**)، ومدة التواجد التقديرية، وإجمالي حركات المسح.
   - زر تصدير فوري لتقرير الحضور والانصراف إلى ملف **Excel / CSV** يدعم الحروف العربية بالكامل (`UTF-8 BOM`).

5. **سجل حركات ودخول شامل مع التصدير (Audit Logs):**
   - توثيق تفصيلي لكل محاولة مسح بالثواني، نسبة التطابق، واسم المستخدم.
   - زر تصدير السجل بالكامل بصيغة **CSV**.

6. **وضع ملء الشاشة لمحطات العمل (Fullscreen / Kiosk Mode):**
   - زر مخصص لتشغيل الواجهة بملء الشاشة وتحويل الكمبيوتر إلى جهاز بصمة وجه مستقل (**Standalone Attendance Kiosk**).

7. **مساحة العمل المحمية وخاصية القفل التلقائي عند الغياب (Workstation Guard):**
   - مساحة عمل متكاملة تتضمن شات محلي فوري (**WebSockets**) وسحابة لمشاركة وحفظ الملفات (**File Vault**).
   - ميزة قفل الأمان التلقائي: في حال ترك المستخدم الشاشة أو تواجد شخص غير مصرح له، يتم قفل النظام تلقائياً لحماية الخصوصية.

8. **تشغيل محلي فائق السرعة وخالٍ من التحذيرات:**
   - يعمل مباشرة بنمط HTTP القياسي على `http://localhost:8000` بدون أي شهادات أمان ذاتية أو أخطاء متصفح.

## 🛠️ المتطلبات والتثبيت

### 1. تثبيت الحزم المطلوبة:
```bash
pip install -r requirements.txt
```

### 2. تشغيل النظام:
- **في بيئة Windows:**  
  انقر نقراً مزدوجاً على ملف:  
  👉 **`run_app.bat`** (أو `run_app.ps1` في PowerShell)

- **أو عبر سطر الأوامر:**
```bash
python -m uvicorn main:app --host 127.0.0.1 --port 8000
```

## 📂 بنية المشروع

```
face-auth-system/
├── models/                     # نماذج الذكاء الاصطناعي (OpenCV ONNX)
│   ├── face_detection_yunet_2023mar.onnx
│   └── face_recognition_sface_2021dec.onnx
├── static/                     # ملفات الواجهة والسكربتات
│   ├── js/
│   │   └── app.js             # محرك الواجهة السايبربانك، تتبع المعالم، والصوت
│   └── ...
├── templates/                  # قوالب صفحات الويب (Jinja2)
│   ├── index.html             # الواجهة الرئيسية (مسح، تسجيل، مستخدمين، حضور، سجلات)
│   ├── portal.html            # البوابة المحمية مع الشات وسحابة الملفات وقفل الغياب

├── database.py                 # قاعدة بيانات SQLite (WAL Mode) والحضور وتصدير CSV
├── face_engine.py              # محرك الذكاء الاصطناعي (YuNet, SFace, Landmarks, Liveness)
├── main.py                     # خادم التطبيق وواجهات البرمجة FastAPI
├── requirements.txt            # المكتبات والاعتماديات
├── run_app.bat                 # ملف التشغيل السريع المباشر
└── run_app.ps1                 # مشغل PowerShell
```
