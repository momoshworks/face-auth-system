# نظام تسجيل الحضور والانصراف والتحقق البيومتري الذكي
### 🏢 Enterprise Smart Biometric Attendance & Access Control System

نظام مؤسسي احترافي متكامل لتسجيل حضور وانصراف الموظفين والتحقق من الهوية عبر بصمة الوجه بالذكاء الاصطناعي، مصمم بواجهة حديثة وأنيقة خالية من التعقيد، مع فصل محطة الحضور العامة عن **لوحة إدارة النظام المحمية** المخصصة حصرياً للمدير.

---

## 🌟 أبرز مميزات النظام

1. **محطة تسجيل الحضور المباشرة (Attendance Kiosk - الشاشة الرئيسية):**
   - **واجهة احترافية نظيفة:** تصميم مؤسسي أنيق ومريح للعين مع ساعة رقمية وتاريخ عربي محدث لحظياً.
   - **فحص بيومتري سريع وتلقائي:** التعرف على وجوه الموظفين ومطابقتها في أجزاء من الثانية عبر محرك **YuNet & SFace ONNX**.
   - **تغذية فورية لسجل الحضور اليومي:** يظهر الموظف فور تسجيل حضوره على الشاشة مع توقيت الحضور الدقيق (وقت الدخول وحالة الصلاحية).
   - **حماية كاملة:** لا يمكن لأي شخص من هذه الشاشة إضافة أعضاء أو التلاعب بالبيانات أو تعديل الصلاحيات.

2. **لوحة تحكم مدير النظام (Admin Console - محمية بالكامل):**
   - الوصول إليها مخصص فقط للمدير عبر الرابط: `http://localhost:8000/admin` (كلمة المرور الافتراضية: `admin123`).
   - كما يمكن للمدير الدخول إليها تلقائياً فور تعرف الكاميرا على وجهه.
   - **الأقسام المتاحة داخل لوحة الإدارة:**
     1. **📊 تقرير الحضور والانصراف:** إحصائيات حية (إجمالي الموظفين، الحاضرون، الغائبون، نسبة الحضور)، فلترة بالتاريخ، وتصدير فوري إلى Excel / CSV مع دعم كامل للأحرف العربية (`UTF-8 BOM`).
     2. **➕ إضافة وتوثيق موظف جديد:** المكان الوحيد المصرح فيه بإضافة الأعضاء الجدد والتقاط صور الوجه بالكاميرا وتحديد المنصب والصلاحيات.
     3. **👥 إدارة الموظفين والصلاحيات:** جدول ببيانات الموظفين، زر سريع لتعطيل أو تفعيل الصلاحية (`Active / Revoked`)، وحذف الموظفين.
     4. **📜 سجل الحركات والمحاولات الأمني (Audit Logs):** توثيق كل محاولة مسح مع التوقيت والنتيجة ونسبة التطابق وتصدير السجل إلى CSV.
     5. **⚙️ إعدادات النظام:** تغيير كلمة مرور مدير النظام ومعلومات المحرك وقاعدة البيانات.

3. **حماية أمنية على مستوى الـ Backend:**
   - واجهات البرمجة الخاصة بالإضافة والتعديل والحذف (`/api/register`, `/api/users/*`) محمية ومقفلة؛ أي محاولة للوصول إليها بدون تسجيل دخول الإدارة يتم رفضها فوراً بكود `403 Forbidden`.

4. **مساحة العمل المشتركة المحمية (`/portal`):**
   - تتضمن شات فوري بين أعضاء الشبكة المحلية وسحابة تخزين ومشاركة الملفات، ولا تفتح إلا لمن يمتلك صلاحية وصول سارية.

## 🛠️ التشغيل السريع

### 1. تثبيت المتطلبات:
```bash
pip install -r requirements.txt
```

### 2. تشغيل البرنامج بنقرة واحدة:
- انقر على: **`run_app.bat`** (أو `run_app.ps1` في PowerShell)
- أو عبر سطر الأوامر:
```bash
python -m uvicorn main:app --host 127.0.0.1 --port 8000
```
