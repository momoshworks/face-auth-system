# نظام التعرف على الوجه، إدارة الصلاحيات ومساحة العمل المشتركة
### 🚀 Face Recognition, Biometric Access Control & Local Team Workspace

نظام أمني متكامل واحترافي للتعرف على الوجوه بالذكاء الاصطناعي عبر الكاميرا المباشرة، مع تسجيل الملفات الشخصية بـ 5 زوايا بيومترية، فحص وتعديل الصلاحيات، وفتح بوابة محمية تتضمن محادثة فورية سحابية ومشاركة ملفات للشبكة المحلية والهواتف الذكية.

---

## 🌟 أبرز مميزات النظام

1. **التقاط الوجه متعدد الزوايا (5D Multi-Angle Enrollment):**
   - معالج ذكي تفاعلي (**Interactive Camera HUD**) يوجه المستخدم خطوة بخطوة بالعد التنازلي والفلاش المرئي.
   - 5 زوايا بيومترية دقيقة: 🎯 الأمام، ➡️ اليمين، ⬅️ اليسار، ⬆️ الأعلى، ⬇️ الأسفل.
   - كشف الوجوه وتحديد المعالم بدقة متناهية عبر شبكة **YuNet ONNX**.
   - استخراج متجهات الخصائص العميقة (128-d Feature Embedding) عبر نموذج **SFace ONNX**.

2. **تسجيل الدخول والتحقق البيومتري الفوري (Ensemble Face Verification):**
   - مطابقة مباشرة للوجه الحي ومقارنته مع جميع زوايا المستخدمين المسجلين في أجزاء من الثانية.
   - حساب نسبة التطابق بدقة (Cosine Similarity).
   - التحقق الصارم من الصلاحيات (`has_access = True/False`) مع رفض فوري للحسابات المعطلة.
   - توليد جلسات دخول مشفرة (`Security Session Tokens`) مخزنة في قاعدة البيانات مع كوكيز آمنة.

3. **بوابة مساحة العمل المشتركة المحمية (`/portal`):**
   - محادثة جماعية فورية عبر **WebSockets** بدون إنترنت خارجي.
   - سحابة تخزين ومشاركة ملفات (**File Vault**) تدعم رفع وتحميل كافة أنواع الملفات وتوثيق الرافع وعداد التحميلات.
   - إحصائيات حية لقاعدة البيانات وأعضاء الشبكة المتصلين.

4. **دعم الهواتف المحمولة وكاميرا البث المباشر (Mobile Live Camera):**
   - خادم مزدوج ذكي:
     - **منفذ HTTP 8000:** لأجهزة الكمبيوتر وشبكة LAN بدون أي تحذيرات أمان.
     - **منفذ HTTPS 8443:** للهواتف المحمولة (Safari / Chrome) لتمكين الكاميرا لايف بنظام WebRTC.
   - نافذة **QR Code** ذكية لمسح الرابط بكاميرا الموبايل والدخول فوراً.
   - زر تبديل الكاميرا (أمامية سيلفي / خلفية).
   - كاميرا مثبتة تفاعلية (**Sticky Camera**) تتكيف مع شاشات الهواتف.

## 🛠️ المتطلبات والتثبيت

### 1. تثبيت المتطلبات (Requirements):
```bash
pip install -r requirements.txt
```

### 2. تشغيل النظام:
- **في بيئة Windows:**  
  انقر نقراً مزدوجاً على:
  👉 **`run_app.bat`** (أو `run_app.ps1` في PowerShell)

- **أو عبر سطر الأوامر يدparamياً:**
```bash
python server.py
```

## 🌐 روابط الدخول

- **من جهاز الكمبيوتر:**  
  👉 **[http://localhost:8000](http://localhost:8000)**

- **من الهاتف المحمول (على نفس الواي فاي):**  
  👉 **`https://[Local-IP]:8443`**  
  *(أو افتح الموقع من الكمبيوتر واضغط على زر **"📱 فتح على الموبايل"** لمسح الـ QR Code مباشرة)*

## 📂 بنية المشروع

```
face_auth_system/
├── models/                     # نماذج الذكاء الاصطناعي (YuNet & SFace ONNX)
│   ├── face_detection_yunet_2023mar.onnx
│   └── face_recognition_sface_2021dec.onnx
├── static/                     # ملفات الواجهة والسكربتات
│   ├── js/
│   │   ├── app.js             # محرك الواجهة والتعرف على الوجه
│   │   └── qrcode.min.js      # مكتبة توليد الـ QR Code محلياً
│   └── ...
├── templates/                  # قوالب صفحات الويب (Jinja2)
│   ├── index.html             # الصفحة الرئيسية والتحقق والتسجيل
│   ├── portal.html            # البوابة المحمية، الشات والملفات
│   └── portal_denied.html     # صفحة حظر الدخول عند عدم وجود صلاحية
├── cert.pem & key.pem          # شهادات الأمان المحلية لتشغيل كاميرا الموبايل
├── database.py                 # إدارة قاعدة بيانات SQLite (WAL mode)
├── face_engine.py              # محرك معالجة ومطابقة بصمات الوجه
├── main.py                     # خادم التطبيق وواجهات البرمجة (FastAPI)
├── server.py                   # مشغل الخادم المزدوج (HTTP + HTTPS)
├── requirements.txt            # المكتبات المطلوبة
├── run_app.bat                 # ملف التشغيل السريع بنقرة واحدة
└── run_app.ps1                 # مشغل PowerShell
```
